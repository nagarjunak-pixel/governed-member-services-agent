# Governed Multi-Tenant Member-Services Agent

A governed, multi-tenant AI assistant for healthcare member-services representatives (`plan_a` — Harborview Health Plan; `plan_b` — Prairie Sky Health), built as a working vertical slice with a centralized tool gateway, evaluation harness with CI regression gate, and production cloud architecture design.
